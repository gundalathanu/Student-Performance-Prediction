# Student Performance Prediction Using Machine Learning

## Project Overview

This project uses machine learning algorithms to analyze
student information and predict academic performance classes.

It includes an interactive dashboard developed using Streamlit.

## Dataset

- Total records: 2,392
- Total columns: 15
- Target variable: GradeClass

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib

## Machine Learning Algorithms

1. Logistic Regression
2. Decision Tree
3. Random Forest

## Dashboard Features

- Student performance overview
- Academic data analysis
- Model performance comparison
- Student performance prediction
- Interactive charts and visualizations
